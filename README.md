# Gold Forecasting Platform

An AI-driven platform that forecasts gold (XAU/USD) price changes using macroeconomic and inflation data.

## Goal
Make macro-driven gold forecasts transparent and accessible to individual investors, small advisors, and researchers, with a public, dated forecast record.

## Status
Under development. Started October 2026.

## Planned
- Automated data collection (FRED and market data)
- A simple baseline forecast and a machine-learning model
- A public dashboard
- A daily, timestamped forecast log

## Disclaimer
For research and education only. Not investment advice.
